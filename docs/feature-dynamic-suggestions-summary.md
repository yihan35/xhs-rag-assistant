## 功能

首页"试试这些问题"从写死的 4 个通用问题 → 根据用户收藏内容 LLM 动态生成个性化引导问题，每次刷新不同。

## 改动

| 文件 | 行数 | 变更 |
|------|------|------|
| `main.py` | +100 / -30 | 新增 `GET /api/suggestions` 端点，含采样逻辑和 LLM 调用 |
| `frontend/src/components/ChatArea.jsx` | +30 / -10 | 硬编码 → 动态获取 + 骨架屏 + fallback |

## 核心流程

```
打开首页，noteCount ≠ null
  → GET /api/suggestions?user_id=xxx
  → 查询收藏（分类分布 + 全量笔记）
  → 采样笔记（数量 = 分类数×2，下限 4 上限 12）
  → GLM-4.6 生成 4 个必须能从收藏中找到答案的问题
  → 每次刷新结果不同（无缓存 + 随机输入 + 随机引导词）
  → 前端：加载中骨架屏 → 显示问题 → 失败/空收藏 fallback 默认
```

## 采样策略

三层递进：

| 层 | 逻辑 |
|-----|------|
| **动态采样量** | `max(4, min(12, 分类数×2))`，随收藏增长自动扩展 |
| **保底层** | 随机选取 N 个分类（≤ 采样量一半），每类 1 条，保证多样性 |
| **加权层** | 剩余名额从全量池加权采样，分类收藏数越多概率越高 |

无论多少分类，至少一半名额留给加权——大类永远有机会多露面，小类也总有保底。

## Prompt 设计

```
System: 根据用户收藏中实际存在的笔记，生成 4 个该用户一定能在收藏中找到
        相关内容的问题。每个问题都必须有至少一篇笔记能回答。
        [随机引导词 5 选 1：实用角度 / 好奇心 / 跨分类组合 / 关注冷门 / 关注热门]

User:   该用户收藏了 N 篇笔记，请从以下笔记中提炼出可回答的问题：
        分类分布：城市生活(5), 军史人物(4), ...
        部分笔记标题：
        - 人生第一100万怎么赚到的！
        - 五一出游，不好玩的照片咱不拍！
        ...

模型：glm-4.6 | temperature=1.0 | max_tokens=200 | thinking=disabled
```

## 关键设计决策

| 决策 | 理由 |
|------|------|
| 无缓存，每次实时生成 | 返回不同问题，保持新鲜感 |
| 随机采样 + 随机引导词 | 增加输入多样性，LLM 输出自然变化 |
| 保底 + 加权双层采样 | 多样性和代表性兼顾 |
| 采样量动态 4-12 | 适配收藏从小到大的长期使用 |
| 保底上限 = 采样量一半 | 防止分类过多时挤掉加权空间 |
| 每问题必须可检索 | 生成的问题锚定实际笔记，点击有结果 |
| 骨架屏 + null 初始态 | 加载过程无默认问题闪现 |
| temperature=1.0 | 高随机性，即使同输入也输出不同问题 |
